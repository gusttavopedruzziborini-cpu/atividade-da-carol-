Sistema simples em C# desenvolvido como atividade de Programação Orientada a Objetos (POO). O projeto simula o cadastro de livros e alunos, além do controle de empréstimos em uma biblioteca escolar.

 Objetivo

Aplicar os conceitos básicos de POO:
